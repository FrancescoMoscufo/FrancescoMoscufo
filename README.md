# Hi, I'm Francesco Moscufo 👋

**Computer Science | Artificial Intelligence & Robotics | Machine Learning Systems**

I'm a developer interested in building intelligent, reproducible software systems at the intersection of **machine learning, network security, and distributed computing**.

My work spans reinforcement learning for software-defined networks, local large language models, semantic retrieval, and application development. I enjoy taking ideas from experimental prototypes to well-documented, testable systems.

## 🔬 What I'm working on

- **Reinforcement Learning for SDN security** — investigating DDoS detection and mitigation with Ryu, Mininet, and OpenFlow, with an emphasis on robustness, generalization, and reproducible evaluation.
- **Local LLMs and coding agents** — exploring open-weight models, vLLM inference, multi-agent orchestration, retrieval, and isolated execution environments.
- **Embeddings and semantic search** — building retrieval and matching pipelines with sentence embeddings, FAISS, and vector databases.
- **Distributed software** — connecting data pipelines, backend services, and user-facing applications.

## 🎯 What matters to me

I care about **reproducible experiments, honest evaluation, clean architecture, and practical engineering**. In research projects, I aim to document not only what works, but also what fails and why.

I'm always interested in exchanging ideas about **AI systems, reinforcement learning, network security, and open-weight LLMs**.
